## 电机增益与调度


| 电机 | ID | 类型 | 更新频率及相位 | 电机 kp/kd | 速度与力矩量程 |
| --- | --- | --- | --- | --- | --- |
| j1 | 1 | ENCOS | 500 Hz，0/2/4/6 ms | 0/35 | ±18 rad/s，±30 N·m |
| j2 | 2 | ENCOS | 250 Hz，1/5 ms | 10/50 | ±18 rad/s，±30 N·m |
| j3 | 4 | ENCOS | 250 Hz，1/5 ms | 10/50 | ±18 rad/s，±30 N·m |
| j4 | 5 | 达妙 | 250 Hz，2/6 ms | 50/.8 | ±45 rad/s，±10 N·m |
| j5 | 6 | 达妙 | 250 Hz，2/6 ms | 25/.8 | ±45 rad/s，±10 N·m |
| j6 | 7 | 达妙 | 250 Hz，3/7 ms | 10/1 | ±45 rad/s，±10 N·m |
| 夹爪 | 8 | 达妙 | 250 Hz，3/7 ms | 8/.1 | ±45 rad/s，±10 N·m |

相位按 8 ms 重复。电机位置量程为 ±12.5 rad。达妙每 75 ms 轮流发送一个 ENABLE。

位置 PID 的 `(kp,ki,kd)`：j1 为 `(6,0,50)`，j2/j3 为 `(4,0,50)`，j4 至夹爪为 `(6,.08,50)`。积分上限为 200。位置 PID 输出上限为 1000 deg/s。j1 至 j3 的积分范围为 1°，其余为 0°。速度 PID 增益均为零，其输出上限分别为 12、12、12、10、10、10、10。

PID 按电机更新周期执行。误差保持不变时，PID 保持当前微分量。ENCOS 进入使能状态时清零 PID 内部状态。

STOP 输出软停机请求。DAMPING 的位置环增益和电机 kp 为零，kd 使用表中值。GRAVITY 六关节的位置环增益及电机 kp/kd 为零。GRAVITY 夹爪保持普通增益，其位置参考跟随反馈。

## 动力学

| 项目 | ARX X5 配置 |
| --- | --- |
| 模型 | 默认 `2023`，可选 `master`、`2025` |
| 模型链 | `base_link → link6` |
| 默认基座重力 | `(0, 0, -9.81)` m/s² |
| RUN 前馈 | `M(q)*qdd_ref + C(q,qd)*qd + G(q)` |
| GRAVITY 前馈 | `G(q)` |
| SDK 重力系数 | `(0.8, 0.8, 0.8, 1.32, 1.32, 1.32)` |
| 可配置粘性前馈 | `radians(参考速度) × viscous_damping`，默认系数为零 |
| 电机力矩 | `direction × (动力学补偿 + 粘性前馈) × torque_scale` |
| 模型数值角度范围 | ±128 rad；实际目标另受机械软限位约束 |

质量、质心和惯量来自 URDF，惯量按 inertial RPY 转到连杆系。模型和算法来源见 [许可证说明](gravity_compensation/PROVENANCE.md)。

## 夹爪找零

1. 每命令周期推进 0.2°，目标超前限制为 20°，闭合前馈为 0.5 N·m。
2. 每 200 ms 检查移动量；连续 3 个窗口小于 0.5°时确认机械限位。
3. 反向退回 142°，误差不超过 4°时设零，再等待 400 ms。
4. 闭合、退回、设零阶段时限分别为 10、6、12 s；找零成功才完成初始化。

## 六轴设零与监控

| 项目 | ARX X5 配置 |
| --- | --- |
| 达妙失能确认 | 上限 1500 ms，每 100 ms 重试 |
| 达妙设零 | 写入后等待 20 ms；必要时使能唤醒并等待 100 ms；每台上限 1000 ms |
| ENCOS 静默 | 设零后 501 ms |
| ENCOS ACK | 等待上限 1500 ms，每台设零上限 2500 ms |
| ENCOS 反馈获取 | 无位置反馈时每 120 ms 尝试软停机获取反馈 |
| 零位容差 | 0.01 rad |
| 整体校准时限 | 15 s |
| 在线监控 | ENCOS 按 10 ms 网格重载 10 次，达妙重载 2 次；维护期间保活本臂 |

校准结束或取消时，对临时唤醒的达妙输出 DISABLE。控制与校准结果通过公共反馈和事件接口读取。
