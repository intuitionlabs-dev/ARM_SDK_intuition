# 后端与链路

SDK 支持 H7 单片机后端和 PC 本地后端。两类后端都向 `sdk.Arm` 提供命令与反馈通道；机械臂型号决定限位、复位参考、夹爪换算及电机配置。

## 执行位置

| 项目 | H7 单片机后端 | PC 本地后端 |
| --- | --- | --- |
| 控制路径 | `sdk.Arm → sdk.Link → 串口 → H7 → CAN → 电机` | `sdk.Arm → LocalLink → ControlSystem → MotorIO → CAN → 电机` |
| 状态机、轨迹和动力学 | H7 固件 | PC Python 控制核心 |
| 设备连接 | 板载 USB CDC 或 USB 转 RS485 | SocketCAN 或 SLCAN，每台臂一条 CAN 通道 |
| 创建入口 | `sdk.Link(...)` | 机械臂包中的 `LocalLink(...)`，继承 `sdk.Link` |
| 型号选择 | `robot_type="arx_x5"` 或 `"metal_arm"`，默认 ARX | 导入 `arx_x5_control` 或 `metal_arm_control` |
| 设备侧支持 | H7 固件须匹配机械臂；型号选项只选择上位机参数 | 包内控制核心提供对应型号的电机协议与模型 |
| 双臂组织 | 一个串口链路，对应 H7 的 CAN1 / CAN2 | 一个本地链路，配置两条独立 CAN 通道 |
| 离线模拟 | `sdk.sim.SimLink`，模拟 H7 协议及状态机 | `LocalLink.simulated()`，运行对应 PC 控制核心 |

`arm_id` 选择连接中的臂，协议版本码用于握手，两者均不识别硬件型号。链路创建后，通过 `sdk.Arm(arm_id, link)` 或 `link.arm(arm_id)` 操作。

具体构造代码见 [Python 调用](PYTHON.md#创建链路)，终端启动参数见 [TUI 调用](TUI.md#启动入口)。

## 公共会话语义

| 操作 | 行为 |
| --- | --- |
| 连接 | 等待握手后的机械臂反馈 |
| 初始化 | 检查状态、全部电机在线及复位姿态容差；成功后进入正常阻尼模式 |
| 启动 | `start()` 请求 RUN，反馈确认后接受运动目标 |
| 运动 | 位置或位置速度目标，关节使用 rad / rad/s，夹爪开口使用 m |
| 复位 | 运动到所选参数的复位角，完成后进入阻尼；不改写电机零点 |
| 设零 | 显式 `set_zero()`，将六轴当前位姿写为电机零点，结果通过 ACK 读取 |
| 保活 | 每台臂有效命令间隔小于 3 s；等待期间也需保活 |
| 读取结果 | 发送返回值表示提交成功；通过状态、模式和反馈判断执行结果 |

初始化内部动作和电机输出的型号差异见 [机械臂差异](ROBOTS.md#控制行为)。H7 的实际执行条件以匹配设备的固件为准。

## 生命周期与诊断差异

| 项目 | H7 单片机后端 | PC 本地后端 |
| --- | --- | --- |
| `open()` | 打开串口，启动接收线程 | 启动本地控制线程；注入的 CAN 适配器由应用管理 |
| `send()` 成功 | 命令已写入串口 | 命令进入本臂队列，每臂容量为 7 |
| 控制拒绝 | 通过后续反馈判断状态 | 反馈及 `drain_events()` 事件 |
| 故障检查 | `link_up`、`feedback_ok`、链路统计与异常 | 同类 SDK 状态与异常，另有 `check_health()` |
| 重连 | 默认自动退避重开串口 | 应用关闭故障设备并重新创建或打开 |
| `reopen()` | 重开通信，读取固件当前状态 | 新建控制器，需重新握手和初始化 |
| `close()` | 关闭串口；H7 按固件超时策略处理 | 停止控制线程并交付电机停机请求，然后由应用关闭 CAN |
| 原始字节与未知 `tid` | 支持协议透传 | 支持已定义 SDK 命令的 payload，拒绝未知类型和字节流注入 |
| 链路统计 | 串口帧、CRC 和 H7 `LinkStatus` | 逻辑消息、队列、漏拍及控制事件；`link_status=None` |

STOP 不提供位置保持或重力补偿。关闭前须放稳或支撑机械臂；H7 关闭串口不等于已经禁用电机。共享链路由创建它的应用统一关闭，`Arm.close()` 只关闭该对象自行创建的链路。

详细参考：[H7 接入](H7.md)、[PC 本地链路](PC_LOCAL.md)、[公共 API](../API.md)。
