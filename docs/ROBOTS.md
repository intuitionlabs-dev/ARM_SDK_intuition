# 机械臂参数与行为差异

ARX X5 和 Metal Arm 使用相同的 `sdk.Arm` 控制方法、SI 单位、状态编号和 TUI 按键。公共流程见 [Python 调用](PYTHON.md) 与 [TUI 调用](TUI.md)。本页列出型号配置与硬件动作差异。

## 参数选择

| 项目 | ARX X5 | Metal Arm |
| --- | --- | --- |
| H7 上位机 `robot_type` | `arx_x5`，默认值 | `metal_arm` |
| 参数模块 | `sdk.board_defs.arx_x5` | `sdk.board_defs.metal_arm` |
| 版本串 / 版本码 | `Intuition-ARX-X5-2023-v0.6` / `0xFD1DDA15` | `Intuition-Metal-Arm-v0.7` / `0xD7D0431B` |

型号选择集中在链路创建处。运行时通过 `link.board_defs` 或 `arm.board_defs` 读取所选参数；同一链路的两台臂共用参数模块。H7 选项配置上位机预检和界面，设备控制由匹配的固件执行。

## 关节与夹爪参数

下表六轴顺序均为 J1～J6。角度以 deg 列出便于对照，Python 控制接口使用 rad；对应常量提供 `_RAD` 形式。

| 参数 | ARX X5 | Metal Arm |
| --- | --- | --- |
| 下限 | `(-115, 0.5, 0.5, -90, -90, -112.87)`° | `(-160, -180, 0, -123, -85, -145)`° |
| 上限 | `(90, 206.26, 171.88, 90, 90, 119.17)`° | `(160, 4.8, 180, 81, 85, 145)`° |
| 复位角 | `(0, 0.5, 0.5, 0, 0, 0)`° | `(0, 0, 0, 0, 0, 0)`° |
| 夹爪原始角范围 | `-157..142`° | `0..2.4` rad |
| SDK 初始化预检容差 | 六轴各不超过 20° | 六轴各不超过 20° |
| 复位参考时长 | 2 s | 2 s |
| 控制拓扑 | 六关节及一个夹爪 | 六关节及一个夹爪 |

`reset()` 使用复位角，`set_zero()` 写入电机零点；两者是独立操作。
ARX X5 的夹爪原始角负向闭合、正向张开。
软限位规定允许的目标角范围，实际闭合点和完全张开点由实测标定确定。

## 控制行为

SDK 负责命令预检、单位换算和反馈读取，状态机及电机动作由匹配型号的 H7 固件执行。接线、遥控器接管和握手条件见 [H7 接入](H7.md)。

| 操作 | SDK 语义 |
| --- | --- |
| 初始化 | 检查电机在线及复位姿态容差；完成后为正常运行 / 阻尼 |
| 显式设零 | 将六轴当前位姿写为电机零点；逐项检查 `SetZeroAck` |
| 复位 | 使用所选复位参考，完成后进入阻尼；不改写零点 |
| STOP | 软停机，不提供位置保持或重力补偿 |
| 关闭串口 | H7 按固件看门狗策略处理失联；不代表电机已禁用 |

初始化中的夹爪动作、STOP 输出和电机使能策略以所用固件为准。退出前应放稳或支撑机械臂。

## 夹爪换算

| 连接 | 默认米制换算 | 使用条件 |
| --- | --- | --- |
| H7，ARX X5 | 文件中的两点标定 | 初始化找零成功，并有该臂的有效标定 |
| H7，Metal Arm | 厂家最近邻查表，`0..0.1 m` | 出厂零点有效 |

公共 API 使用 `gripper_m`，换算由所选存储负责。`sdk.Arm(..., calib_store=...)` 可指定实测标定；未提供夹爪目标时保持当前反馈角。原始角接口 `gripper_raw_deg` 适用于设备调试，数值范围随型号变化。

文件标定提供 `full_open_m`、`direction` 等两点模型字段；厂家查表提供双向角度/开口换算。上层控制使用 `gripper_opening` 或 `snapshot()`，不依赖换算对象的特有字段。标定文件与工具见 [配置说明](../config/README.md)。

## 参数来源

ARX X5 的限位、复位参考与协议版本对应 H7 固件配置。
Metal Arm 的限位与夹爪查表取自厂家 `metal-python-ros` 的 `bccf3c8` 版本，分别对应 `motor_config.cpp` 与 `can_manager.h`；版权及 MIT 许可保留于 [LICENSE.MakerMods](../board_defs/LICENSE.MakerMods)。六轴复位参考定义于 `sdk.board_defs.metal_arm.RESET_POSE_DEG`。
