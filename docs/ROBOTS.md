# 机械臂参数与行为差异

ARX X5 和 Metal Arm 使用相同的 `sdk.Arm` 控制方法、SI 单位、状态编号和 TUI 按键。公共流程见 [Python 调用](PYTHON.md) 与 [TUI 调用](TUI.md)。本页列出型号配置与硬件动作差异。

## 参数选择

| 项目 | ARX X5 | Metal Arm |
| --- | --- | --- |
| H7 上位机 `robot_type` | `arx_x5`，默认值 | `metal_arm` |
| PC 包 | `arx_x5_control` | `metal_arm_control` |
| 参数模块 | `sdk.board_defs.arx_x5` | `sdk.board_defs.metal_arm` |
| PC 默认动力学模型 | `2023` | `metal_with_gripper` |
| PC 可选模型 | `2023`、`master`、`2025` | `metal_with_gripper`、`metal_no_gripper` |

型号选择集中在链路创建处。运行时通过 `link.board_defs` 或 `arm.board_defs` 读取所选参数；同一链路的两台臂共用参数模块。H7 选项配置上位机预检和界面，设备控制由匹配的固件执行。

## 关节与夹爪参数

下表六轴顺序均为 J1～J6。角度以 deg 列出便于对照，Python 控制接口使用 rad；对应常量提供 `_RAD` 形式。

| 参数 | ARX X5 | Metal Arm |
| --- | --- | --- |
| 下限 | `(-115, 0.5, 0.5, -90, -90, -112.87)`° | `(-160, -180, 0, -123, -85, -145)`° |
| 上限 | `(90, 206.26, 171.88, 90, 90, 119.17)`° | `(160, 0, 180, 81, 85, 145)`° |
| 复位角 | `(0, 0.5, 0.5, 0, 0, 0)`° | `(0, 0, 0, 0, 0, 0)`° |
| 夹爪原始角范围 | `-142..142`° | `0..2.4` rad |
| PC 初始化姿态容差 | 六轴各不超过 20° | 六轴各不超过 20° |
| PC 复位轨迹 | 2 s | 2 s |
| 控制拓扑 | 六关节及一个夹爪 | 六关节及一个夹爪；无夹爪负载模型也使用七电机拓扑 |

`reset()` 使用复位角，`set_zero()` 写入电机零点；两者是独立操作。

## 控制行为

本表描述 PC 后端。H7 固件执行策略见 [H7 接入](H7.md)。

| 项目 | ARX X5 PC | Metal Arm PC |
| --- | --- | --- |
| 初始化内部动作 | 六轴复位后执行夹爪找零 | 六轴复位，夹爪保持初始化入口反馈角 |
| 初始化完成 | 正常运行 / 阻尼 | 正常运行 / 阻尼 |
| 显式设零 | 六轴 ENCOS / 达妙设零与反馈确认 | 六轴达妙设零与反馈确认 |
| STOP 使能 | 达妙每 75 ms 轮流选择一台发送 ENABLE | 无已知故障电机各至少间隔 75 ms；4 ms 调度下通常为 76 ms |
| STOP 输出 | 零增益、零力矩软停机 | 零增益、零力矩软停机；标零参与电机暂停周期使能 |
| 关闭控制器 | 全部 SOFT_STOP，达妙额外 DISABLE | 全部七台电机 DISABLE |
| RUN 动力学 | `M*qdd + C + G`，SDK 系数作用于 G，另加可配置粘性摩擦 | 默认缩放 G、C 与粘性摩擦；关闭 SDK 缩放时使用完整 `M*qdd + C + G` |
| 电机控制 | 主机位置 PID 配合电机混控 / MIT 增益 | 电机原生 MIT PD，主机级联 PID 增益为零 |

STOP 的模式语义相同，周期使能策略由电机协议和后端实现决定。需要保持承重时，应使用适合当前设备和姿态的控制模式；STOP 与退出会释放承重力矩。

## 夹爪换算

| 连接 | 默认米制换算 | 使用条件 |
| --- | --- | --- |
| H7，任一参数型号 | 文件中的两点标定 | 固件零点与实测标定一致 |
| PC，ARX X5 | 文件中的两点标定 | 初始化找零成功，并有该臂的有效标定 |
| PC，Metal Arm | 厂家最近邻查表，`0..0.1 m` | 出厂零点有效 |

公共 API 使用 `gripper_m`，换算由所选存储负责。`sdk.Arm(..., calib_store=...)` 可指定实测标定；未提供夹爪目标时保持当前反馈角。原始角接口 `gripper_raw_deg` 适用于设备调试，数值范围随型号变化。

文件标定提供 `full_open_m`、`direction` 等两点模型字段；厂家查表提供双向角度/开口换算。上层控制使用 `gripper_opening` 或 `snapshot()`，不依赖换算对象的特有字段。标定文件与工具见 [配置说明](../config/README.md)。

## 电机协议与调度

| 项目 | ARX X5 PC | Metal Arm PC |
| --- | --- | --- |
| 电机协议 | J1～J3 ENCOS；J4～J6 及夹爪达妙 MIT | 全部达妙 MIT |
| 发送 ID | `1, 2, 4, 5, 6, 7, 8` | `1, 2, 3, 4, 5, 6, 7` |
| 达妙接收路由 | 仲裁 ID 0，载荷低 4 位为电机 ID | 仲裁 ID `0x11..0x17`，同时校验载荷电机 ID |
| 位置编码量程 | ±12.5 rad | ±6.28 rad |
| 速度编码量程 | 前三轴 ±18，其余 ±45 rad/s | 前四轴 ±10，其余 ±30 rad/s |
| 力矩编码量程 | 前三轴 ±30，其余 ±10 N·m | ±`(30,120,30,30,20,20,20)` N·m |
| 电机输出周期 | J1 为 2 ms，其余 4 ms | 全部 4 ms |
| 设零与查询静默 | ENCOS 存在 501 ms 静默期 | 达妙维护流程 |

两者使用 1 Mbps 经典 CAN 标准帧。编码量程用于报文归一化，不等于电机额定性能；CAN 反馈使用输出轴坐标。增益、零点处理及模型来源分别见 [ARX 控制参数](../arx_x5_control/PC_PORT.md) 与 [Metal 控制参数](../metal_arm_control/PC_PORT.md)。
